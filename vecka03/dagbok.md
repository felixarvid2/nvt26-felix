3.17 [typ 7 • Återblick] Vad är skillnaden mellan running-config och startup-config?
(Kapitel 1)
running config är den som gäller just nu medan enheten är på. startup config är den config som gäller när man startar enheten. Man måste spara running config med write memory för att den ska sparas i startup config
